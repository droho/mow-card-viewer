# Man O' War Card Viewer 0.7.0

Unofficial, non-commercial fan-made reference viewer for Man O' War.

## Public scope

- 73 unit profiles with graphical unit-card presentation;
- authoritative HIGH / HIGH+LOW / LOW hit-location target-band presentation from accepted Data Core v13;
- weapon diagrams from the accepted WD1E lineage;
- 219 game cards across 17 decks, including 114 magic cards in 6 magic decks;
- rules / FAQ browser;
- two-unit comparison;
- PL / EN interface;
- responsive desktop and mobile layouts.

The standalone Card Emulator / deck-state prototype is intentionally not part of this release.
